# Face Detection System using OpenCV

## 📖 Overview
This project implements a real-time Face Detection system using OpenCV and Haar Cascade Classifier.  
The system detects human faces from images or live webcam feed.

## 🚀 Features
- Face detection from images
- Real-time face detection using webcam
- Haar Cascade classifier
- Clean and modular Python code

## 🛠️ Tech Stack
- Python
- OpenCV
- NumPy

## 📂 Project Structure
Face-Detection/
│── data/
│── models/
│── src/
│── requirements.txt
│── README.md

## ▶️ How to Run

1. Clone the repository
2. Install dependencies:

pip install -r requirements.txt

3. Run the program:

python src/recognize.py
